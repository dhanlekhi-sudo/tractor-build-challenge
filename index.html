Before you dive in

This is a working prototype, not a live system.

Everything you're about to see — orders, channel mix, foot traffic, printer status — is built to show the shape of a real head-office dashboard, not to be one yet.

  • It's a draft. There's no real database behind it — the "order book" is a handful of readable data files, not Postgres or Supabase.
  • No production hosting or domain. It's static files on GitHub Pages — good enough to demo, not to run a business on.
  • All the data is mock. Every order, dollar figure, and foot-traffic number is illustrative, chosen to tell a plausible story — none of it is measured from a real Tractor store.
